## 1. AI / LLM

**Mistral 8x22B 'Fusion' 모델 출시 및 벤치마크 업데이트** ⭐
Mistral AI가 새로운 Mixture-of-Experts(MoE) 기반 대규모 언어 모델 'Mistral 8x22B Fusion'을 공식 출시했습니다. 이 모델은 총 1760억 개의 파라미터를 활용하며, MMLU(Massive Multitask Language Understanding) 벤치마크에서 89.2점, HumanEval 코딩 벤치마크에서 82.5점을 기록하며 기존 Mistral 모델 대비 성능 향상을 보였습니다. 특히 효율적인 토큰 처리와 고품질의 복합 추론 능력을 강점으로 내세웁니다.
**왜 주목할만한가:** MoE 구조의 효율성 덕분에 실시간 교통 예측, 복잡한 교통 상황 분석 및 최적화된 경로 제안 등 ITS 분야의 까다로운 추론 작업에 필요한 고성능 AI 애플리케이션 개발에 유리한 선택지를 제공합니다.

**딥시크, 오픈소스 AI 코딩 에이전트 '슈퍼 에이전트' 공개** ⭐
딥시크(DeepSeek)는 LLM이 복잡한 프로그래밍 작업을 스스로 수행할 수 있도록 돕는 오픈소스 코딩 에이전트 시제품인 '슈퍼 에이전트(Super Agent)'를 선보였습니다. 이 에이전트는 사용자의 명시적인 호출 없이도 코드 작성, 디버깅, 테스트 등 개발 워크플로우 전반에 걸쳐 자율적으로 작동하는 것을 목표로 합니다. 초기 공개 버전은 GitHub 리포지토리에서 접근 가능하며, 다양한 LLM 백엔드와의 연동을 지원합니다.
**왜 주목할만한가:** ITS 개발자들은 슈퍼 에이전트를 활용하여 복잡한 교통 시뮬레이션 코드, 센서 데이터 처리 로직, 관제 시스템 인터페이스 등 ITS 소프트웨어 개발 과정에서 반복적이고 시간이 많이 소요되는 작업을 자동화하여 생산성을 대폭 향상시킬 수 있습니다.

**PyMuPDF 2.0 업데이트 및 LLM용 데이터 변환 도구 'PyMuPDF4LLM' 출시** ⭐
오픈소스 PDF 처리 라이브러리인 PyMuPDF가 버전 2.0으로 업데이트되면서, LLM 학습 및 추론에 최적화된 데이터 변환 도구 'PyMuPDF4LLM'을 별도 패키지로 제공하기 시작했습니다. PyMuPDF4LLM은 PDF 문서에서 텍스트, 이미지, 테이블 레이아웃을 정확하게 분석하여 LLM이 이해하기 쉬운 구조화된 형태로 변환하는 기능을 강화했습니다. 이는 복잡한 PDF 문서의 의미론적 분석을 용이하게 합니다.
**왜 주목할만한가:** ITS 개발 환경에서 교통 관련 규제 문서, 도로 설계도면, 센서 데이터 보고서 등 방대한 양의 PDF 문서를 LLM 학습 데이터로 활용하거나, 실시간 정보 추출 시스템을 구축하는 데 필요한 데이터 전처리 작업을 효율적으로 수행할 수 있습니다.

**Cursor IDE, 버전 0.30 출시: GPT-4 Turbo 및 Claude 3 Opus 통합 강화**
AI 네이티브 코드 에디터인 Cursor IDE가 버전 0.30을 출시하며 주요 LLM과의 통합을 한층 강화했습니다. 이번 업데이트를 통해 사용자들은 OpenAI의 GPT-4 Turbo 및 Anthropic의 Claude 3 Opus 모델을 코드 생성, 질문 답변, 코드 리팩토링 등 다양한 코딩 작업에 직접 활용할 수 있게 되었습니다. 또한, 인라인 챗 기능의 반응 속도와 정확성이 개선되었으며, 새로운 사용자 지정 프롬프트 템플릿 기능이 추가되었습니다.
**왜 주목할만한가:** 최신 고성능 LLM을 개발 워크플로우에 직접 통합함으로써 ITS 개발자들은 교통량 예측 알고리즘, 신호 제어 로직, 자율주행 센서 융합 코드 등 복잡한 ITS 애플리케이션 개발 시 코드 자동 완성, 버그 수정, 성능 최적화 등에서 탁월한 생산성 향상을 경험할 수 있습니다.

## 2. 보안 & 취약점

**VMware vSphere 제로데이 취약점 (CVE-2026-41709) 긴급 패치 권고**
미국 CISA(사이버보안 및 인프라 보안국)는 VMware vSphere의 제로데이 취약점인 CVE-2026-41709를 실제 악용 취약점 목록(KEV)에 추가하고, 연방 민간 기관에 2026년 11월 11일까지 보안 조치를 완료하도록 요구했습니다. 이 취약점은 중국 해커조직 '워프 판다(Warp Panda)'에 의해 악용되어 서버 침해 후 흔적 은폐에 사용된 것으로 확인되었습니다.
**왜 주목할만한가:** ITS 인프라는 종종 가상화 환경 위에서 운영되므로, 이 치명적인 제로데이 취약점은 서비스 중단, 데이터 유출 또는 시스템 제어권 탈취로 이어질 수 있습니다. ITS 개발팀은 즉시 해당 CVE에 대한 패치 적용 여부를 확인하고 필요한 보안 조치를 취해야 합니다.

**Quest KACE 관리 플랫폼 제로데이 취약점 4종 (CVE-2025-8875 외) 발견 및 악용**
미국 정부 기관은 중국 해커조직 '볼트 타이푼(Volt Typhoon)'이 Quest KACE 관리 플랫폼의 제로데이 취약점 4종(CVE-2025-8875, CVE-2025-8876, CVE-2026-20127, CVE-2026-16812)을 악용하여 미국 핵심 인프라 시스템에 침투했다고 경고했습니다. 이 취약점들은 원격 코드 실행 및 권한 상승을 가능하게 하여 광범위한 시스템 침해로 이어질 수 있습니다.
**왜 주목할만한가:** ITS 시스템의 관리 및 배포에 Quest KACE와 같은 솔루션이 사용될 수 있으므로, 해당 취약점은 ITS 운영 환경에 심각한 보안 위험을 초래합니다. 관련 솔루션을 사용하는 개발자 및 운영팀은 즉시 취약점 패치를 확인하고 시스템 모니터링을 강화해야 합니다.

## 3. 개발 도구 & 프로그래밍

**Google Cloud 'Julls' 서비스 2025년 종료 예정, 11월 11일부터 읽기 전용 전환**
Google Cloud는 개발자가 백그라운드에서 코딩 작업을 처리하던 서비스 'Julls'를 2025년 12월 31일부로 종료한다고 발표했습니다. 이에 앞서 2025년 11월 11일부터는 해당 서비스가 읽기 전용 모드로 전환됩니다. Julls는 특히 GitHub 저장소의 코드를 Google Cloud 가상머신에 복제하여 작업을 처리하는 데 사용되었습니다.
**왜 주목할만한가:** Julls를 활용하여 GitHub 코드 기반의 CI/CD 파이프라인이나 자동화된 개발 작업을 수행하던 ITS 개발팀은 Google Cloud Build, Cloud Run 또는 다른 CI/CD 도구로의 전환 계획을 수립하고, 코드 백업 및 마이그레이션 전략을 마련해야 합니다.

**VS Code 1.93 업데이트: GitHub Copilot Chat 개선 및 웹뷰 API 확장**
Visual Studio Code가 버전 1.93 업데이트를 통해 GitHub Copilot Chat 기능을 크게 개선했습니다. 이제 Copilot Chat은 코드 컨텍스트를 더 정확하게 이해하고, 복잡한 질문에 대한 답변 품질이 향상되었으며, 새로운 명령 세트가 추가되었습니다. 또한, 웹뷰(Webview) API가 확장되어 개발자들이 더욱 풍부하고 인터랙티브한 사용자 경험을 제공하는 확장 기능을 개발할 수 있게 되었습니다.
**왜 주목할만한가:** ITS 애플리케이션 개발 시 VS Code를 사용하는 개발자들은 개선된 Copilot Chat을 통해 더욱 효율적인 코드 작성, 디버깅, 문서화 작업을 수행할 수 있습니다. 확장된 웹뷰 API는 맞춤형 ITS 개발 도구나 시각화 도구를 VS Code 내에 통합하는 데 활용될 수 있습니다.
