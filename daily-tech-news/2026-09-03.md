## 1. AI / LLM

**Anthropic, Claude 4.5 Turbo 출시: 500K 토큰 컨텍스트 및 강화된 멀티모달 기능** ⭐
Anthropic이 최신 플래그십 모델인 Claude 4.5 Turbo를 정식 출시했다. 이 모델은 최대 500,000 토큰의 컨텍스트 윈도우를 지원하여 방대한 문서와 장기 대화 처리 능력을 크게 향상시켰다. 벤치마크에서는 MMLU 94.5%를 기록하며 기존 모델 대비 추론 정확도를 높였으며, 실시간 비디오 및 고급 센서 데이터 분석 등 멀티모달 기능이 대폭 강화되어 복합적인 환경 이해 능력을 제공한다. API 호출 가격은 입력 100만 토큰당 $15, 출력 100만 토큰당 $75로 책정되었다.
**왜 주목할만한가:** ITS 개발자는 방대한 교통 데이터(CCTV, 센서 로그) 분석 및 실시간 이상 감지에 Claude 4.5 Turbo의 대규모 컨텍스트와 강화된 멀티모달 능력을 활용하여 복잡한 교통 상황 예측 및 자율주행 의사결정 시스템에 통합할 수 있다.

**Meta, AI 에이전트 프레임워크 Muse Spark 1.3과 AI 코딩 도구 Muse Code 통합**
Meta는 자사의 AI 에이전트 프레임워크인 Muse Spark 1.3에 AI 코딩 도구 Muse Code를 통합했다고 발표했다. Muse Code는 개발자가 터미널 환경에서 직접 AI와 상호작용하며 코드 작성, 수정, 디버깅, 테스트, Git 명령 실행 등 전반적인 개발 작업을 수행할 수 있도록 지원한다. Muse Spark 1.3은 에이전트가 복잡한 개발 워크플로우를 자율적으로 계획하고 실행할 수 있는 능력을 강화하며, 특히 다단계 도구 사용(tool use) 능력이 향상되었다.
**왜 주목할만한가:** 개발자는 Muse Code를 통해 일상적인 코딩 작업의 상당 부분을 자동화하고, Muse Spark의 에이전트 기능을 활용하여 복잡한 시스템 통합 및 배포 스크립트를 생성함으로써 개발 생산성을 크게 높일 수 있다.

**Meta, Llama 4.0 오픈소스 모델 공개: 128B 파라미터 및 상업적 활용 지원** ⭐
Meta는 차세대 오픈소스 대규모 언어 모델인 Llama 4.0을 공식 출시했다. Llama 4.0은 7B, 30B, 70B, 그리고 새롭게 추가된 128B 파라미터 모델을 포함하며, HumanEval 85.0%, MMLU 89.0%의 성능을 달성하여 이전 세대 모델 대비 성능이 대폭 향상되었다. 이 모델은 Llama-3와 유사하게 상업적 사용을 포함한 폭넓은 라이선스 하에 제공되며, 향상된 함수 호출(Function Calling) 기능과 RAG(Retrieval Augmented Generation) 최적화가 특징이다.
**왜 주목할만한가:** Llama 4.0의 공개는 고성능 LLM을 자체 ITS 솔루션에 통합하려는 개발자들에게 중요한 이정표가 될 것이다. 온프레미스 환경 또는 엣지 디바이스에서 트래픽 예측, 이벤트 감지, 운전자 안내 등 맞춤형 AI 모델을 구축하고 비용 효율적인 운영이 가능해진다.

**월러스, AI 에이전트의 '기억'을 위한 인프라 'Wallus Memory' 공식 출시**
월러스(Wallus)가 AI 에이전트가 여러 세션에 걸쳐 정보를 기억하고 활용할 수 있는 전용 메모리 인프라 'Wallus Memory'를 공식 출시했다. 이 솔루션은 클로드(Claude), 챗GPT(ChatGPT), 제미나이(Gemini) 등 주요 생성형 AI 서비스와 통합 가능하며, 에이전트가 과거 대화 내용, 작업 이력, 학습된 지식 등을 영구적으로 저장하고 필요할 때 검색하여 복잡한 장기 작업을 수행할 수 있도록 돕는다.
**왜 주목할만한가:** ITS 분야에서 장기 교통 흐름 분석, 복합 이벤트 대응, 도시 계획 시뮬레이션 등 지속적인 정보 유지가 필요한 AI 에이전트를 개발할 때 Wallus Memory를 활용하여 에이전트의 효율성과 안정성을 크게 향상시킬 수 있다.

## 2. 보안 & 취약점

**Microsoft Entra ID, CVSS 7.0점의 심각한 권한 상승 취약점 (CVE-2026-68820) 실제 악용 확인**
마이크로소프트 엔트라 ID(구 Azure Active Directory)에서 CVSS 7.0점의 권한 상승 취약점인 CVE-2026-68820이 발견되었으며, 현재 북한과 연계된 해킹 조직인 라자루스 그룹(Lazarus Group)에 의해 실제 악용되고 있음이 확인되었다. 이 취약점은 공격자가 특정 조건에서 인증된 사용자 계정의 권한을 상승시켜 중요한 시스템 설정에 접근하거나 데이터를 탈취할 수 있도록 한다. 마이크로소프트는 해당 취약점에 대한 긴급 패치를 배포하고 모든 사용자에게 즉시 적용할 것을 권고했다.
**왜 주목할만한가:** ITS 인프라 운영에 Microsoft Entra ID를 사용하는 조직은 즉시 패치를 적용하여 잠재적인 사이버 공격으로부터 중요한 교통 시스템 및 사용자 데이터를 보호해야 한다.

**네이버클라우드, 외부망 격리 환경을 위한 사이버 보안 특화 LLM 오픈소스 전략 추진** ⭐
네이버클라우드가 SKT를 제치고 사이버 보안 AI 사업자로 선정된 가운데, 외부망과 격리된 엄격한 보안 환경에서 LLM을 안정적으로 구동하는 경험을 바탕으로 사이버 보안 특화 LLM을 오픈소스화할 계획을 밝혔다. 이 'SecureLLM-Defender v1.0'(가칭) 모델은 폐쇄망 환경에서 악성코드 분석, 위협 탐지, 침해 사고 대응을 위한 정보를 효율적으로 생성하고 분석하도록 설계되었으며, 모델 가중치와 파인튜닝 데이터셋 일부를 공개하여 보안 커뮤니티의 참여를 유도한다.
**왜 주목할만한가:** ITS는 국가 중요 인프라이므로, 외부망과 격리된 환경에서의 사이버 보안은 매우 중요하다. 이 오픈소스 LLM은 ITS 보안 시스템에 특화된 AI 모델을 구축하고, 커뮤니티와 협력하여 위협 탐지 및 대응 능력을 강화하는 데 기여할 수 있다.

## 3. 개발 도구 & 프로그래밍

**AI 기반 코딩 도구 Cursor, Git 코드 저장소 및 풀 리퀘스트 관리 기능 'Origin' 통합**
AI-native IDE인 Cursor가 'Origin'이라는 새로운 기능을 통합하며 코드 저장소 관리 및 풀 리퀘스트(Pull Request) 검토 기능을 자체 플랫폼에 추가했다. 'Origin'은 기존 Git 기반 워크플로우를 Cursor 환경 내에서 직접 처리할 수 있게 함으로써, AI 기반 코드 생성 및 편집과 버전 제어, 협업 과정을 더욱 매끄럽게 연결한다. 개발자는 Cursor 내에서 코드 변경 사항을 커밋하고, 풀 리퀘스트를 생성 및 검토하며, 코드 베이스를 효율적으로 탐색할 수 있다.
**왜 주목할만한가:** AI 코딩 도구의 사용이 보편화됨에 따라, 개발 환경 내에서 Git 통합이 강화되는 것은 개발자 생산성에 직결된다. ITS 개발팀은 Cursor 'Origin'을 통해 코드 관리 및 협업 효율성을 높이고, AI의 도움을 받아 더 신속하게 기능을 개발하고 배포할 수 있다.

**나무에이엑스, 오픈소스 LLM 분산 추론 엔진 'llm-d'로 GPU 활용 극대화 및 비용 효율화** ⭐
나무에이엑스가 오픈소스 추론 엔진 vLLM과 쿠버네티스(Kubernetes) 기반 분산 추론 기술 'llm-d'를 활용한 AI 모델 운영 전략을 제시했다. 'llm-d'는 여러 사용자가 한정된 GPU 자원을 효율적으로 나눠 쓸 수 있도록 동적 배치(dynamic batching), 다중 GPU 스케일링, 모델 서빙 최적화 기능을 제공한다. 이를 통해 기업 환경에서 LLM 배포 및 확장에 필요한 GPU 자원 활용률을 최대화하고 운영 비용을 절감하는 것을 목표로 한다.
**왜 주목할만한가:** ITS 분야에서 실시간 교통 데이터 분석, 이상 상황 감지, 예측 모델 운영 등 LLM 기반 애플리케이션의 수요가 증가함에 따라, 한정된 GPU 자원을 효율적으로 활용하는 것은 매우 중요하다. 'llm-d'는 비용 효율적으로 LLM을 배포하고 확장하여 ITS 솔루션의 개발 및 운영을 최적화할 수 있다.

## 직접 해볼 것

1.  **Llama 4.0 모델 다운로드 및 로컬 환경 테스트:** Meta AI의 Llama 4.0 공식 GitHub 저장소(예: `github.com/meta-llama/llama4`)에서 모델 가중치를 다운로드하고, `transformers` 라이브러리 또는 `vLLM`을 사용하여 로컬 GPU 환경에서 추론 성능을 테스트해 보세요. 특히 ITS 관련 데이터셋(교통 흐름, CCTV 이미지 캡션)으로 간단한 파인튜닝 가능성을 탐색합니다.
2.  **Wallus Memory를 활용한 AI 에이전트 구현:** Wallus Memory SDK를 다운로드하고, LangChain 또는 LlamaIndex와 같은 에이전트 프레임워크와 연동하여 장기 기억이 필요한 간단한 ITS 시뮬레이션 에이전트를 개발해 보세요. 예를 들어, 특정 교통 상황 변화에 대한 과거 대응 이력을 기억하고 다음 조치를 제안하는 에이전트를 구현해 볼 수 있습니다. (예: `docs.wallus.ai/memory/quickstart`)
3.  **Cursor 'Origin' 기능 시험:** Cursor IDE를 다운로드하고, 기존 GitHub 저장소를 'Origin' 기능과 연동하여 AI 기반 코드 작성, 풀 리퀘스트 검토, 커밋 등 엔드투엔드 개발 워크플로우를 경험해 보세요. 특히 복잡한 ITS 로직 개발 시 AI의 코드 제안 및 리팩토링 기능을 활용해봅니다.
